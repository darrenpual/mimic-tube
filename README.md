# 미믹 튜브

우리 영상을 올리고 보는 웹사이트(영상 플레이어 포함). 외부 패키지 없이 Node.js 18 이상만 있으면 됩니다. ffmpeg가 있으면 썸네일과 영상 길이가 자동으로 만들어집니다.

```bash
node server.mjs          # http://localhost:4400
PORT=5000 node server.mjs
```

- 영상 올리기: 오른쪽 위 **업로드** 버튼, 또는 페이지에 파일을 끌어다 놓기(최대 4GB)
- `videos/` 폴더에 영상 파일을 직접 넣어도 자동으로 목록에 올라옵니다.
- 기능: 검색 · 최신순/인기순 · 조회수 · 좋아요 · 댓글 · 제목/설명 수정 · 삭제 · 링크 공유 · 다운로드 · 이어보기 · 다음 영상 자동 재생

## 플레이어 단축키

| 키 | 동작 |
| --- | --- |
| Space / K | 재생·일시정지 |
| J / L | 10초 뒤로 / 앞으로 |
| ← / → | 5초 뒤로 / 앞으로 |
| ↑ / ↓ | 볼륨 |
| M | 음소거 |
| F · 더블클릭 | 전체 화면 |
| T | 극장 모드 |
| 0~9 | 영상의 0%~90% 위치로 이동 |
| < / > | 재생 속도 |

## 저장 위치

- `videos/` 영상 파일 · `data/videos.json` 목록·댓글·조회수 · `data/thumbs/` 썸네일
